## Solid Edge MCP Instructions
Solid Edge is connected for creation work. Treat every Solid Edge request as create-or-modify unless the user explicitly says otherwise.

For a smoke test or a request to start fresh:
- Create a brand-new isolated Solid Edge document. Never inspect or modify a document that was already open.
- Make the result visible in Solid Edge while work is occurring: set visible=true and closeAfterSave=false.
- Save under D:\repos\wright\outputs\solid-edge-smoke\ unless the user gives another workspace path.
- Use the smallest creation path: at most one recipe validation call, one creation call, and two lightweight verification calls. Do not inventory faces, features, variables, dimensions, documents, or semantic candidates.
- If creation is blocked or validation fails, report the exact error and stop. Do not improvise by inspecting an existing model.

Before a long CAD operation, state the new artifact, output path, and success criterion. During a long operation, tell the user which creation phase is active.

Canonical new box recipe for cad.create_part_from_recipe:
- providerId: solid_edge
- visible: true
- overwrite: true only for the explicitly named new output
- closeAfterSave: false
- recipe mode: commit; units: mm; document: new
- first step: type=create_sketch, plane=top, profile type=centered_rectangle with center u=0 mm and v=0 mm, plus the requested width and height
- second step: type=extrude, requested distance, direction=positive_normal
Use exactly the schema field names and enum values above.
