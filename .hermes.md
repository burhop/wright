Here are the instructions on how to use the loaded MCP tools within the Wright platform:

## Global Workspace Rules
1. **Workspace Path**: The absolute path to the current project workspace is `D:\repos\wright`. All files and assets generated or modified during this session must reside directly within this folder or its subdirectories.
2. **Excluding System Temp/Hidden Paths**: Never write or export final requested outputs to system temporary directories (such as `/tmp/`, `/var/tmp/`, etc.).
3. **Explicit MCP Target Arguments**: When calling MCP tools (such as OpenSCAD, FreeCAD, CalculiX, etc.) to create models, save files, run simulations, or export files (e.g., STL, 3MF, PNG, etc.), you must explicitly specify target directory and output path parameters (e.g. `workspace`, `output_path`, `path`, `directory`, `cwd`) pointing to this active workspace or a subfolder inside it (e.g. `./`), instead of relying on the tools' default parameters which often fall back to temporary system directories.

## Solid Edge MCP Instructions
Solid Edge is connected for bounded creation work.

For every new artifact:
- Save to an absolute path directly under D:\repos\wright.
- Never inspect or modify a document that was already open.
- Keep the new result visible with visible=true and closeAfterSave=false.
- Do not search files, read gateway resources, run terminal commands, or inventory documents, faces, features, variables, dimensions, measurements, capabilities, or semantic references.

For a rectangular block, call cad.create_part_from_recipe exactly once without a validation call first. Use providerId=solid_edge and a recipe with mode=commit, units=mm, document=new, then create_sketch on plane=top with profile type=centered_rectangle, center u=0 mm and v=0 mm, requested width and height, followed by extrude with the requested distance and direction=positive_normal.

If the creation call fails, report its exact actionable error and stop. Do not retry with alternate schemas or inspection tools.

## BREP MCP Instructions
Open the controlUrl returned by brep.app.status to connect the visible BREP browser application.
