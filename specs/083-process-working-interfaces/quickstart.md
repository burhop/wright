## Operator journey to deliver

1. Open a saved process from the workspace and inspect its accepted source.
2. Open Working view in a workspace tab. Provide choices/images/files and check
   readiness. Required late choices are collected here.
3. Choose Create interface, describe useful layout and let Wright generate/validate/
   build. See progress; preview opens as a tab. Save the built revision.
4. Start a prepared process explicitly. Follow actual activity/tool contributions,
   inspect results/findings and respond only at declared interaction checkpoints.
5. Switch between tailored/common/editor views; navigate to exact contributing
   block and evidence. Close/reopen and retain the same run.
6. Inspect final preparation/analysis evidence and any required review. Submission,
   completed digital outputs and engineering acceptance remain different facts.
7. Reuse the saved UI on a new run. Update after a required binding changes; the
   common view remains available. Reopening alone does not regenerate or dispatch.
