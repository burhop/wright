## User journey and ownership

An engineer opens a saved assignment, resolves the declared inputs, runs the
accepted process and inspects the actual engineering deliverables and findings.
The diagram and working view refer to the same backend-owned run, exact artifacts
and planned decisions. Tool-specific CAD, drawing and slicing stay with existing
independent providers. Wright supplies the runtime, gateway, immutable results,
082 validation/rework/reviews, process client, UI kit and workspace tabs.

Geometry, material, profile and accepted instruction changes invalidate dependent
evidence and decisions. Layout changes do not. Missing required capabilities hold
their dependent work and remain visible; neither a generated UI nor an AI verdict
fills that gap. Saved interfaces remain bound/versioned and fall back to the
common view when incompatible. Historical claims are preserved with dated scope
reassessment rather than overwritten.
