## Findings

### CR-NATIVE-01 — P2 — Keep structurally invalid commands outside the working definition

`apps/web/src/components/native-process/model.ts`, `validateDocument`, checks the shared schema and several semantic invariants, but omits the artifact-path semantic check and only enforces one producer when cardinality is `one` (line 348). This permits two commands the official backend language rejects. `NativeInspector.tsx:206–216` clears the field buffer after `command` reports success, so this is observable state loss of the last valid field configuration, not merely a delayed readiness warning.

Reproduction A: add an `artifact.input@1` step, apply `safe.txt`, then apply `../outside.txt`. `applyCommand` succeeds and commits `../outside.txt` to the working definition. Authoritative `validate_definition` rejects the identical bytes with `ARTIFACT_PATH`. The field should remain buffered, with the previous valid config intact. Backend workspace confinement remains effective; this finding does not claim a filesystem escape.

Reproduction B: load a structurally valid unknown-operation draft with `many`-valued ports and one producer, then connect a second `many` output to that input. The frontend accepts the added connection; the backend rejects it with `MULTIPLE_PRODUCERS`. The language permits a single producer for every input; cardinality describes its value, not an exception to the producer rule.

Retained independently authored probes: `.local-run/review-client-invariants.mjs`, `.local-run/client-accepted-path.json`, `.local-run/review-many-input.mjs`, `.local-run/many-before.json`, `.local-run/many-after.json`. The Node probes fail against this candidate; the Python authoritative validator supplies the corresponding rejection codes. Node 25.2.0 executed the actual TypeScript model through built-in type stripping, using discovery output generated by this checkout's actual Python core.

Requested correction: make local atomic command validation conform to those authoritative invariants, preserving invalid Inspector text and the prior valid document; cover both cases with focused regressions.

### CR-NATIVE-02 — P2 — Preserve and disclose the agreed undo window

`apps/web/src/components/native-process/model.ts:540` retains `history.past.slice(-49)` plus the current document, giving only 50 undo commands. `NativeEditor.tsx` displays Undo/Redo controls without the limit. The frozen `contracts/native-process.md:13` explicitly requires 100 commands and a visible limit.

The independent probe applies 60 title changes, observes only 50 retained commands, then exhausts Undo and remains at `Edit 10`, rather than the original `Untitled process`. This silently discards promised session recovery well within an ordinary 25-step authoring journey. Saving does preserve the remaining history; the problem is its smaller undisclosed bound.

Requested correction: retain 100 atomic commands and disclose the bound in the editor, with a focused boundary regression and a component assertion for the visible explanation.
