# Quickstart

1. Confirm ordinary workspaces work when editor support is disabled.
2. Enable support with no manifest and confirm a typed missing diagnostic.
3. With a test manifest, bootstrap a selected workflow, read, save, reopen.
4. Retry from another session, after expiry, and with stale revision; no file
may change.
5. Disable support: grants become unusable and authored files remain untouched.
