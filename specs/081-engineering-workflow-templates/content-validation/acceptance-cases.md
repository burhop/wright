## Independently calculable reference values

The three thermal-link briefs define one-dimensional models:

`T_hot = T_cold + Q × [L/(k × W × t) + R_contact]`

Lengths are in metres and contact resistance is the total interface resistance in K/W. These values are calculations from the supplied input assumptions, not observations from workflow outputs.

For heaters, an independent reference may use the requested lumped balance
`(m cp + C_vessel) dT/dt = η P − UA (T − T_ambient)`,
provided the actual approved kit implements equivalent assumptions. Such a reference is a checker; it cannot substitute for required Modelica execution. Where the kit cannot express the input physics, the correct disposition is a specific unsupported-model finding.
