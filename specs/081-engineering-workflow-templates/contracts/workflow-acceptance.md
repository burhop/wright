## Promotion gate

A template begins as `reference`. It may become `setup_required` when its exact selected operations and requirements are valid, `ready` when configured qualified integrations are currently available, and `verified` only after one current real Wright run passes all declared assertions plus a negative/recovery case. Status applies to a named template/integration/version/environment evidence subject, not an entire server or engineering discipline.

The UI milestone may ship all ten reviewed definitions with fixtures and previews. It cannot mark them live from deterministic/static scenario summaries. Each flagship workflow must earn its own verified state before it is described as working.
