# Wright desktop walkthrough

**0.15.0 is prepared, not installed yet.** First ask:

> Check Wright's connection status and tell me which version and capabilities are active. Do not start a workflow.

After the named update is verified, use a fresh conversation on the existing GB10
host. Keep this file open in another tab. No desktop restart is needed.

1. **Open:** “Open Wright home in the panel beside this conversation.”
2. **Workspace:** “Create a Wright workspace called Desktop UI Check and open it.”
   Visit Workflows, Connections, Files and Runs; return to Workflows.
3. **Create:** “Create a small digital inspection-brief workflow for a 120 × 80 ×
   6 mm plate with four 8 mm holes. Treat unspecified hole locations as missing
   information. Save it and open its shared editor; do not start it yet.”
   Try Diagram, Source, an inspector, Undo/Redo and Save. Close and reopen it.
4. **Run:** Open **Run and results**, prepare the inputs, then Start.
   Say: “Continue this exact Wright run using this conversation for its pending
   reasoning. Use Wright to save the response.” Inspect its terminal result.
5. **Files/history:** Upload a small nonsecret file in Files, preview/download it,
   then reopen the completed run from Runs. Confirm the download actually arrived
   on Windows; a successful tool reply alone is insufficient.
6. **Connections:** Inspect a saved provider's readiness, workspace availability
   and individual tool switches. Installing a plugin does not grant Wright tools.
   Do not install a new provider or begin personal sign-in just for this check.

If a request loses its reply, ask: “Read the existing receipt and run; do not start
another run or repeat an uncertain action.” Report bugs with the screen/control,
expected behavior and what happened. Screenshots are welcome; omit secrets.

Generated interface authoring, background chat wakeups and automatic restart of
an interrupted reasoning task remain unavailable. This brief is not a measured
inspection or manufacturing approval.
