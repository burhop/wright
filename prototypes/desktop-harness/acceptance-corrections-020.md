# Desktop 0.20 acceptance corrections

The experimental desktop panel now retains the exact selected completed run when opening a producing step. The shared recorder reader checks workspace, session, workflow, run and source identities; the existing editor projects that read-only evidence. It does not acquire execution or approval authority. Missing run context is distinct from a genuine edited-source mismatch, which still detaches result evidence.

Home, Reopen and history display accepted workflow titles. Search also matches normalized filenames; exact paths remain inspectable. File previews move focus and scroll their loaded content into view, then return focus to the opener when closed. Connections shows saved activity and workspace enablement alongside authentication limits, validation age and host compatibility. Completed setup opens saved information rather than an unsolicited sign-in flow.
