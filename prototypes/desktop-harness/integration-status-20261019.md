Wright retains accepted source, durable runs, gateway authority, validation,
declared inputs/reviews and recovery. The native panel adds Workflows,
Connections, Files and Runs without a second chat/sidebar hierarchy. The neutral
shared canvas and common process view remain shared with Hermes.

historical evidence. It does not revise their original outcomes. Installation,
repository integration, host verification and personal consent remain separate.

and an unclassified scanner execution failure. The
