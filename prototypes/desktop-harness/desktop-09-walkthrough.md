Use a fresh conversation on the existing GB10 host. The installed plugin is
`wright-desktop-gb10-prototype` 0.9.0. Do not restart the desktop.

1. Paste: **“Check the Wright connection, then open Wright home.”**
2. Select **Private native review proof**. Open **Files**, click **Refresh**,
   and confirm the workspace and Files view stay selected.
3. Open **Workflows → native-review.workflow.wflow**. Try Diagram and Source.
   Use **Workspaces** to return. Save any edits before leaving.
4. Open **Recent runs**, select that workflow, then **Inspect run**.
   It should show the completed private run and its recorded synthetic review.
   Opening it must not start another run.
5. Report any awkward controls, missing content or navigation that loses your place.

private native review proof. Read only; do not start or continue anything.”**
