# Wright 0.11: quick desktop check

Open a fresh conversation on the existing GB10 host. No desktop restart is needed.

1. Say: **“Open Wright home.”** Confirm the Wright panel appears beside chat.
2. Select your test workspace, or use **New workspace**. Open **Workflows**.
3. Use **New workflow**, make a small edit, save, go Back, and reopen it. Confirm your edit is retained.
4. Open **Connections**. Use the custom HTTPS connection form to preview a public MCP URL you intend to use. Check its name and URL before reviewing or creating a setup plan. Creating a plan does not connect or enable the provider.
5. Go Back and reopen Connections. Confirm the saved plan remains discoverable. Do not approve/apply a test provider you do not intend to install.
6. Narrow the panel and try Files and Recent runs. Report any clipped controls, confusing labels, missing state or failed navigation.

For SteveCAD, use the existing catalog and account. Sign-in still needs the Windows-to-GB10 callback route verified first. This check does not establish CAD execution or engineering acceptance.

Useful feedback: which step failed, what you expected, and a screenshot with private account details hidden. Browser test results on GB10 are separate from this actual Windows check.
