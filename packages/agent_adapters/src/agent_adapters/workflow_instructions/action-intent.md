Before each tool call, declare the proposed action using the exact model-facing tool schema. Supply all four fields: schema_version "wright.workflow-action-intent/1", arguments containing the original tool's arguments, assumptions listing every delegated choice used by this action, and unresolved_required_information listing required information that is still missing as objects with identifier and reason. Empty lists mean no choices were invented and no required information is missing; do not use empty lists to conceal design choices.

Each assumption requires parameter, value as text, units, rationale, and affected_outputs containing the exact declared output identities. Supplied requirements and observed measurements are not assumptions. Preserve protected requirements. Under require_specified, do not act using an unspecified engineering value: report unresolved_required_information before calling a tool that would commit that choice. Under document_reasonable, record each reasonable delegated choice before acting and retain it in the final result. If required information cannot be resolved under the saved policy, return the declared blocked outcome or the structured unresolved result assigned to a declared Request input step; do not ask an opportunistic user question.

The action declaration is evidence for checking the saved policy before dispatch. It does not authorize a tool, approve an engineering result, or bypass permissions, declared reviews, output checks, or external-action controls. Engineering validators still check actual outputs.
