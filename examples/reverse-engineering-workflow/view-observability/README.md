# Choose observations that can detect shape errors

This optional instruction asset refines the existing evidence-survey step for
comparison planning. Supply the existing request, photos, measurements or earlier
survey as ordinary inputs; the engineer need not build a register first. It adds
no mandatory stage or UI. Use the same evidence-survey builder with the explicit
`instruction_asset` and `response_schema` dictionaries loaded from this directory.
Omitting both retains the original survey instructions and schema.

The plan distinguishes what each observation can constrain from what it cannot:
an outline may constrain an envelope while leaving a recess depth unresolved.
View names, automatic camera fitting and matching colors do not establish camera
calibration. Proposed masks, parameter perturbations and checks remain plans until
executed. Unknown scale can permit dimensionless image analysis while preventing
a physical-dimensional claim. Questions remain data for a declared input step.

The builder embeds the selected instruction body and response schema into newly
authored source. It neither edits an accepted workflow nor resumes a run. Wright's
existing input, readiness, model routing, execution, evidence, validation and
review owners remain authoritative. The existing common view/editor can inspect
the JSON plan; no new UI binding or client version is required. An unavailable
model/image capability holds readiness; an unavailable observation is a named
feature gap, not a fabricated measurement or a failure of unrelated work.

Changes to source images, CAD revisions, configuration, camera treatment or
instructions require new accepted inputs/source and revalidation of affected
comparisons. Fitting and held-out evidence must retain their dependency groups.
Plan status is not a backend validation verdict or human acceptance.

The motivating bounded Windows experiment rendered exact historical SteveCAD
STEP revisions with a known pocket-depth change. Front, right and top PNGs were
pixel-identical; the isometric pair differed. Independent sections measured the
depth. This qualifies that observation, not every renderer or reconstruction.
Local exact run/artifact and Astra request evidence is retained separately in the
pilot's `native-render-sensitivity-01` and observability qualification records.
No full automatic CAD correction loop or vehicle accuracy is established here.
