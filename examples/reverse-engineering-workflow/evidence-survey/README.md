# Inspect supplied evidence before modeling

This optional preparation step accepts a plain request plus existing images or
documents. It organizes visible evidence by component, feature, view and
configuration. The engineer does not have to prepare an evidence register first.
Use the research-first workflow for missing information; this step performs no
web search and creates no CAD.

`build_workflow.py` declares a normal saved Wright source. Its attachments are
already uploaded, confined workspace paths. The existing source compiler,
instruction snapshots, model adapter, input storage and durable runner own
execution. `survey-instruction.json` is an Astra-authored versioned instruction
asset; `survey-response-schema.json` describes the result. The common result
view remains usable; no custom interface or second executor is introduced.

The survey distinguishes visible appearance, reported claims, measurements,
calculable constraints, hypotheses and hidden geometry. It records movable-state
differences and dependent images before proposing fitting or validation views.
It plans perspective projection and masks without claiming camera calibration
or physical dimensions. Missing scale stays unresolved. Crops and related views
are not automatically independent evidence, and thresholds are never invented.

The selected source IDs, hashes and image contents must travel together. Changed
references, configuration, scale or instructions require a new accepted source
or input snapshot and invalidate affected downstream comparisons. An unavailable
image is an explicit inspection gap. A requested model or image capability that
is unavailable must hold readiness rather than silently fall back. User choices
are output fields for later declared interaction; this survey does not answer
them or manufacture approval.

Before reconstruction, resolve consequential choices, bind permitted producer
and measurement tools, and define the comparison scope supported by the actual
evidence. Validation views must be excluded from geometry fitting. Camera
calibration using scored features is diagnostic fitting, not independent
validation. Retain exact candidate revisions and revalidate after corrections.

Local qualification is recorded separately from this portable example. A
compiled source or schema-valid report alone does not establish visual
inspection, numerical accuracy, engineering acceptance or a complete CAD loop.
