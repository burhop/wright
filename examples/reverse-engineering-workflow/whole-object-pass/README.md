# Whole-object reverse-engineering pass

Optional authoring/refinement instructions for reaching a complete exterior
before spending iterations on local details. Inputs remain simple text, images,
data and an existing evidence package. This general asset is local pilot work;
it is not an accepted workflow change or a qualified automatic CAD loop.

Reuse the existing configured agent adapter, tool runtime, durable runs,
validation, exact artifacts and declared human interactions. New instructions
must be included in a visible new workflow revision; saved workflows and frozen
runs retain their prior bodies and routing. No executor, service or UI is added.

For a vehicle, separate panels and a consistent closed configuration help avoid
fitting incompatible states. For a fixture or enclosure, the same strategy
prioritizes its complete envelope and meaningful interfaces before local detail.
These examples do not establish cross-domain execution qualification.

Record observed configuration per component and image before grouping views.
For example, a stowed airfoil in a top view and a raised airfoil in a rear view
must not become one closed-state silhouette target. Keep the raised view as
separate pose evidence. Using its fixed body requires explicit corresponding
visible regions and exclusion of movable or occluded regions; a caption alone
does not perform that exclusion. If the consistent-pose rear reference has no
registered comparison, show it as reference-only and leave that check pending.
Do not infer a hinge, opening angle or hidden geometry from a pose label.

Restrict comparison metrics to the recorded features or explicit inclusion
masks. A rectangular crop can still contain moving-part edges. Treat regions
revealed only by an opened component as state-specific evidence; they do not
establish the closed-state gap, hidden depth or connecting surface.
