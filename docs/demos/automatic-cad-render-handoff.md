# Automatic native CAD rendering handoff

The engineer supplies a design prompt, receives a specification and test plan,
then inspects measured CAD and a faithful illustrated review. SteveCAD owns CAD
creation and inspection. AgentCAD's existing standard-format exporter prepares
the actual CAD surfaces for Blender's existing native renderer. Wright owns the
accepted process, durable execution, exact file dependencies, results and review.

The original seven-stage v13 process is retained. Its screenshot-derived AI
renderings changed visible geometry, a demonstrated general limitation. The
native-rendering change is justified by that limitation; it does not justify a
different process per design, a second executor or reduced engineering checks.
