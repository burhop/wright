# Robot-arm revision 7 design package

Open `design-review.html` for the illustrated review. It links the engineering
document, preconstruction plan, original failed review, scoped verification,
native captures, three final exact-geometry renderings and motion MP4.

The original run completed but engineering acceptance is still open. This is an
additive evidence package, not a replacement or approval of that run. The STEP
and 18 oriented STL files are digitally verified; physical printing, assembly,
drives, stability, loads and operation remain unverified. The review identifies
the remaining required work. No material is published.
