# Compact Test Plan — Robot Arm Revision 6 Metadata Cleanup

## 1. Controls and verdict rules

Test document `167ef21f-6679-4e4d-8917-14dc067893d6`, CURRENT revision 6/build `82a810f5-a5f5-481f-84d3-fd997dfaa4bd`, then the single generated successor revision. Use native B-rep inspection; source code, labels, historical exports and rendered pixels are not proof of generated geometry.

Record measured values, method, native tolerance and evidence reference. PASS requires the stated comparison. Measured noncompliance is FAIL; absent or inapplicable evidence is UNVERIFIED. Rendering and final-document checks are deferred until those outputs exist and are not CAD-inspection failures.

Frames: assembly world is right-handed, +X right, +Y rear, +Z up; reach is toward −Y. Component-envelope tests use each definition’s native local frame before mapping its declared build direction to printer +Z. Never apply the stationary-group footprint bound to moving components.

## 3. Required capture set

At Stage 6, set the assembly to home and capture exactly once each: isometric, world top looking along −Z, and world front showing the prescribed +X/+Y/+Z orientation. Do not hide geometry needed to count visible holes, slots, fasteners, PCB or moving links. Record revision/build and camera orientation with each capture. Produce three studio derivatives only after native captures exist; they may improve lighting and appearance but may not alter silhouette, pose, visible feature count or geometry.

## 4. Release condition

No requirement with missing evidence may pass. CAD inspection may close only geometry, count, interface, clearance, motion and native-capture checks. R16 and R18–R20, plus the rendering and document portions of R17/R19, remain deferred until their outputs exist. Any post-generation geometry change, second edit, count mismatch, measured tolerance violation or unenumerated overlap is FAIL and cannot be waived to obtain acceptance.
