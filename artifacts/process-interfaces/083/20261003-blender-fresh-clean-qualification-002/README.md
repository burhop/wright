# Fresh selected Blender qualification

A neutral Linux/amd64 Wright image was verified without Blender or its MCP.
Only this selected provider, pinned independent addon, Blender 4.3.2 and its
virtual-display prerequisites were installed in a separate selected image.
Original base image and Wright runtime dependencies were not changed.

Official initialize/tools/list discovers 28 tools. Their input schemas exactly
match the prefixed production gateway projection. One actual guarded gateway
call exports a 12-triangle STL: measured 10 x 8 x 6 model units, volume 480.
STL is unitless. This small backend qualification is not an engineering assignment,
physical verification, user acceptance or qualification of every listed tool.

The first call used obsolete export syntax after creating a cube and failed.
Its response and native log remain. After verifying the first session/container
stopped, a fresh isolated session used the observed host's wm.stl_export operator.
No provider source was patched and no uncertain action was replayed. The selected
installation is reused for this correction; it is not installed twice.

Both backend sessions have network disabled and one isolated workspace mount.
The production api.gateway_stdio runs in the current Windows source environment.
All three exact labeled installer/runtime containers are revalidated stopped.
Credentials, private databases and contexts are excluded; metadata/logs use the
shared redactor. Exact geometry bytes and a hashed inventory are retained.
T043 and the complete Feature 083 goal remain open at their wider scope.
