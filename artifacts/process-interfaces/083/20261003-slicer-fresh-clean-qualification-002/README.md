# Fresh selected slicer qualification

A neutral Linux/amd64 Wright image was checked without this MCP or slicer host.
The pinned independent MCP and official Bambu Studio 2.8.2.61 AppImage were
installed with fresh selected Python/cache directories and selected free host
prerequisites in a separate image. The base image is unchanged. Official release
metadata and its matching SHA-256 are retained; no provider source was patched.

Official initialization/listing discovers eleven tools. All input schemas match
Wright's prefixed production gateway projection. One actual slice_model_file
call through api.gateway_stdio creates an exact 30,054-byte 3MF with nonempty
G-code. Independent byte readback confirms PETG, density 1.28, four walls,
35% infill, 0.2 mm layers, supports enabled and the selected machine. These
unchanged preset files are explicit provider configuration, not Wright profile
resolution code. Supports enabled does not prove that this tiny model needs
supports or that a preview is an optimal engineering orientation.

The backend runs without a display, with network disabled and one isolated
workspace mount. The gateway runs in the current Windows source environment;
this does not establish a clean in-container API installation. No printer tool,
real printer credential, physical job, catalog promotion or human review is used.
All three exact labeled attempt/install/runtime containers are revalidated stopped.

The first evidence-helper type error occurred before installation. Its record
is retained. The fresh second attempt reuses only the verified official download;
it installs the selected dependencies once. There is no backend action to replay
from the first attempt. Metadata/logs use Wright's shared redactor; original
input/package/profile bytes and a hashed inventory are retained. Private state
databases and credentials are excluded.

Reproduction records: release.json identifies the official asset and checksum;
installation-command.json records selected installation; qualification.json
records resolved packages, CLI help, exact image and source pin; tools.json and
gateway-tools.json record actual schemas; gateway-definition.json and gateway/
result.json record the exact offline invocation and receipt. Use a fresh
isolated directory/container and network-disabled backend for a new probe.

This closes the missing clean selected slicer installation/protocol/backend/
gateway scope. It does not complete T043, full original scenario qualification,
engineering acceptance or Feature 083's broader UI/migration/regression audits.
